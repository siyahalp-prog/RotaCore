# Rota Analytics

Privacy-conscious product analytics for Rota products.

## Tracking

```ts
import { AnalyticsService, InMemoryAnalyticsStore } from '@rota-core/analytics';

const analytics = new AnalyticsService(new InMemoryAnalyticsStore());

await analytics.trackPageView({
  sessionId,
  visitorId,
  pageUrl: '/scholarships',
  referrer: document.referrer,
  userAgent: req.headers['user-agent'],
});

await analytics.track({
  eventName: 'scholarship_saved',
  sessionId,
  visitorId,
  userId, // optional, when logged in
  properties: { scholarshipId },
});
```

Stored fields: `page_url`, `referrer`, `event_name`, `event_properties`,
`session_id`, `visitor_id`, `user_id?`, `user_agent` (+ coarse `browser`/`device`),
`country?` (placeholder), `correlation_id?`, `created_at`.

## Browser script

`apps/api` serves `GET /track.js` (generated by `buildTrackingScript(endpoint)`):

```html
<!-- RotaGlobal integration (placeholder domain — update after deploy) -->
<script src="https://analytics.rota.app/track.js"></script>
<script>
  // custom events
  rota.track('scholarship_saved', { scholarshipId: 'sch-1' });
</script>
```

The script auto-tracks a page view, keeps a random visitor id in
`localStorage` and a session id in `sessionStorage`, and uses `sendBeacon`.

## Aggregations (dashboard API)

- `pageViewsByDay(from, to)`
- `topPages(from, to)` / `topReferrers(from, to)`
- `eventsByName(from, to)`
- `activeUsers(reference)` → DAU / WAU / MAU (distinct visitor or user id)
- `funnel(['view_scholarship', 'signup', 'save_scholarship'], from, to)` →
  ordered conversion per step

## Privacy

- No raw IP storage by default; `country` is a placeholder to be filled by a
  privacy-friendly edge lookup, never persisted IPs.
- No fingerprinting: visitor id is a random UUID the user can clear.
- `optOut: true` (and `navigator.doNotTrack` in the script) drops events.
- User agents are reduced to coarse browser/device families.
